## What was implemented
Wrapped the filter+sort computation in ExpenseList inside useMemo so it only
recalculates when `expenses` or `filters` change. Previously it ran on every
render, including unrelated state changes (toast appearing, modal open/close).

## Files modified
- src/components/ExpenseList.tsx
  Line 3:  added `useMemo` to React import
  Lines 35-57: wrapped `filtered` chain in useMemo(() => ..., [expenses, filters])

## Diff summary
  import { useState } from 'react';
→ import { useState, useMemo } from 'react';

  // Filter + sort
  const filtered = expenses.filter(...).sort(...);
→ // Memoised: only recomputes when expenses or filters change
  const filtered = useMemo(() => expenses.filter(...).sort(...), [expenses, filters]);
